# ColumnistRail

The rail of columnists: a round initials badge, the name in tracked Condensed caps and a one-line teaser.

## Anatomy
- Roundel: 44px circle, `gator-blue` with `on-deep` initials, ringed with `paper` then a 2px `orange` ring (the one round control besides the live dot).
- Name: `rail-title`-weight caps (14px/800); teaser: `column-story`, `ink-2`.
- Rows divided by 1px `rule`.

## Use it
- Newest column first. Two columns side by side from 600px.
