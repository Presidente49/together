# GameBoard

The stage section for game week: a white-text board on `deep` with a dot screen and a 4px `orange` foot.

## Anatomy
- Ground `deep` (Gator blue by day, near-black navy at night); everything on it is white-based: `on-deep`, `deep-ink`, `deep-body`, `deep-label`.
- Top line: `pill` (`orange-ink`/`on-orange`) then date, kickoff and venue in `deep-ink`.
- Match: two team rows, `board-score` numerals tabular; two columns from 821px.
- Latest list with `deep-label` lead-ins; links as outlined buttons (`shadow-ring-deep`), the first filled `orange-ink`.

## Use it
- Saturday game days only, or when the desk turns it on. Records come from ESPN, never typed.

## Don't
- No dark text on deep and no `orange` text; the orange appears only as the foot rule.
