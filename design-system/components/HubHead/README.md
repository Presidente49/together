# HubHead

The title of a hub section: a 40px uppercase Condensed 800 heading with a quiet line at right, on the `hub` tint.

## Anatomy
- Ground: `hub` (#eef2fb) with `space-24` padding; modules inside sit on `card`.
- Title: `hub-head`; supporting line `meta`-weight 13px in `ink-2` (7.1:1 on hub).
- Quick links beneath as Chips.

## Use it
- One per hub block ("LATEST", "GAME WEEK", "COLUMNISTS").
