# Kicker

A one-line uppercase label that names the column, franchise or destination above a headline.

## Use it
- Above the lead headline, a columnist's latest piece, and every right-rail panel.
- Write it in title or sentence case; CSS sets it uppercase. Real kickers: "The Buddy Martin column", "The Big Read", "Only at GatorBait", "Game Week Reference", "Watch & Listen", "The GatorBait community".
- Use `orange-text` on `paper` or `stone`. On a `navy` panel add `gb-kicker--on-navy` for `peach`.

## Markup
`<p class="gb-kicker">The Buddy Martin column</p>`. The consumer supplies the text; the container sets spacing (16px above, 9px below on the front page).

## Don't
- Don't color it `orange`; at 11px it needs `orange-text` to reach 4.5:1.
- Don't write a kicker longer than about four words, or use it as a category tag on every card.
