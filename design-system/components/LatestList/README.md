# LatestList

The hub's chronological list: a time-ago stamp, a Condensed headline and a meta line, separated by 1px `rule` lines.

## Anatomy
- Module: `card` fill, 16px side padding, uppercase module title (`rail-title`).
- Row: 52px stamp column in `link` (Condensed 700, 12px), headline in `latest-headline` (normal case), then `meta`.

## Use it
- Five to eight rows. The stamp is relative ("2h", "1d").
- Whole row is the link; the headline underlines on hover.
