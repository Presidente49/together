# PlanCard

A membership plan: a square card on `paper` with a `plan-line` border and a 4px `orange` top rule.

## Anatomy
An optional ribbon (`navy`, 700 11px), the plan name in Barlow 800 at 25px, `plan-price` with its period in `slate-meta`, a short benefit line in `ink-body`, and a `gb-button--block`.

## Use it
- Prices, trials and checkout come from Wix's native plans; this only restyles them. Never hard-code a price that isn't the live plan's. The prices in the preview are placeholders.
- Keep cards the same height in a row, and put the ribbon on one plan at most.
- The consumer supplies the plan name, price, period, benefits and checkout action.
