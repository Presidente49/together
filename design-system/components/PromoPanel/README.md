# PromoPanel

A right-rail block that sends readers to a destination: the Magazine, GatorBait TV, a game-week reference or the community.

## Variants
- **`gb-panel--magazine`**: `navy` fill, `on-navy` text, `peach` kicker, a 4px `orange` top rule, `space-28` padding. The one filled block on the page; use it only for GatorBait Magazine.
- **`gb-panel--watch`**: on `paper` between a 3px `navy` rule and a `rule` hairline. For Watch & Listen, Game Week Reference and the community.

## Use it
- Kicker, headline in `panel-headline`, one or two sentences in `body-small`, then stacked `gb-panel-link`s.
- Say only what is true. No live badges, schedules or "now open" claims the product doesn't back; the community panel reads "The GatorBait Message Board is being prepared. Discussion is not open yet."
- The consumer supplies the copy and destination URLs.
