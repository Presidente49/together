# PullQuote

A quote set off by a 4px `orange` bar: Condensed 700, 28px (38px desktop), `link` colour, with orange curly marks.

## Anatomy
- Bar: `border-4` `orange`; 16px left padding (24px desktop).
- Quote: `pull-quote` style; marks added by CSS, not typed.
- Cite: speaker in tracked caps (`ink`), role and date in `cite` (`ink-2`).

## Use it
- One per page. Quotes must be verbatim and attributed.
- The same shape is the game-day quote card.
