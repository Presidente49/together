# SectionTitle

The label that opens a module: 18px Barlow 800 at -0.04em under a 4px `orange` rule.

## Use it
- One per module: "Latest", "More from the newsroom". The rule marks where a module starts, so don't add another border above it.
- The rule is always `border-4` in `orange`.

## Markup
`<h2 class="gb-section-title">Latest</h2>`. The consumer supplies the text and the list that follows.
