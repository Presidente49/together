# VoicesBand

A full-width band that surfaces each columnist's newest piece: `stone` ground between 2px `navy` rules.

## Use it
- Label column: the kicker "Only at GatorBait" and "The voices you come for." in `band-headline`.
- One column per columnist (Buddy Martin, Franz Beard), each behind a `rule-soft` divider: the kicker is the columnist's name, then the headline in `story-headline`, then `meta`.
- Grid `.85fr 1fr 1fr` with `space-28` gap and padding. One column at 820px, with rules on top instead of at the left.
- Don't repeat the lead story here. If the lead is Buddy's newest column, show his next one.
- The consumer supplies one latest story per columnist.
